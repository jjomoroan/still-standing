Still Standing Demo — готовый статический сайт (PWA).

КАК ВЫЛОЖИТЬ НА GITHUB PAGES
1. Создай публичный репозиторий на github.com.
2. Add file -> Upload files.
3. Перетащи в корень репозитория СОДЕРЖИМОЕ этой папки:
   index.html, manifest.webmanifest, service-worker.js, иконки, .nojekyll.
   Не загружай саму папку share-site — index.html должен быть в корне.
4. Settings -> Pages -> Deploy from a branch -> main / (root) -> Save.
5. Через 1-2 минуты открой:
   https://USERNAME.github.io/REPO/
6. Отправь ссылку друзьям. ZIP отправлять не нужно.

WINDOWS
- Открой ссылку в Edge или Chrome.
- Edge: ... -> Apps -> Install this site as an app.
- Chrome: иконка установки в адресной строке или меню -> Установить приложение.
- Приложение появится в Пуске, работает в отдельном окне и офлайн после
  первого открытия. Данные хранятся в браузере.

HUAWEI-ПЛАНШЕТ
- Открой ссылку в Huawei Browser.
- Меню -> Добавить на главный экран.
- Если пункта нет — добавь в закладки; приложение всё равно работает.
- Не очищай данные сайтов, иначе локальный прогресс исчезнет.

ДАННЫЕ
- У каждого пользователя свой localStorage; синхронизации нет.
- Резервная копия — Экспорт/Импорт JSON внутри приложения.
