# Still Standing Demo

**«Всё ещё на ногах»** — локальный трекер задач с мягкой геймификацией:
отмечаешь сделанное, получаешь баллы, растёшь в уровнях, выбираешь класс,
открываешь титулы, фокусируешься по таймеру, пишешь заметки и тратишь баллы
на собственные награды.

Слоган: **стальной характер · мягкий дофамин**.

## Открыть приложение

**https://jjomoroan.github.io/still-standing/**

Это PWA: ссылку можно открыть в браузере, а можно установить как приложение.

### Windows

1. Открыть ссылку в Edge или Chrome.
2. Edge: `…` → **Apps → Install this site as an app**.
3. Chrome: иконка установки в адресной строке или `⋮` → **Установить приложение**.
4. Приложение появится в «Пуске» и на панели задач.

После первого открытия оболочка кэшируется — приложение работает и без
интернета. Данные хранятся в браузере.

### Huawei-планшет

1. Открыть ссылку в Huawei Browser.
2. Меню `⋮` → **Добавить на главный экран**.
3. Если пункта нет — добавить в закладки; приложение всё равно работает.

Не очищайте «данные сайтов» браузера, иначе локальный прогресс исчезнет.
Для резервной копии внутри приложения есть **Экспорт/Импорт JSON**.

## Данные

- У каждого пользователя свой `localStorage`; синхронизации между устройствами нет.
- Сервер не хранит задачи, баллы и заметки — только отдаёт статический код.
- Это статический сайт: HTML/CSS/JS без внешних зависимостей.

## Обновления

После обновления приложения достаточно заменить файлы в репозитории.
Пользователям — закрыть и открыть приложение или обновить страницу; данные
сохраняются.

## Структура

- `index.html` — приложение;
- `manifest.webmanifest` — PWA-манифест;
- `service-worker.js` — офлайн-оболочка;
- иконки и `apple-touch-icon.png`;
- `.nojekyll` — для GitHub Pages.
